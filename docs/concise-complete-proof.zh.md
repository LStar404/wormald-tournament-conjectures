# 原猜想 1、2、6：一篇先读的完整证明导读

本文概述三个原命题的对象、量词和证明链。对应 Lean 入口现已完整证明这些主命题；所用计数、解析、矩比较和取等分类均已接回原定义，没有遗留数学假设。这里不讨论历史优先权，也不将伴随的路径、单调性或高阶展开加强表述为已完成的形式化结论。

## 对象与三个命题

::: {.definition title="实际样本模型与圈数"}

取奇数 $d\ge3$，基础锦标赛 $T$ 有 $d$ 个顶点。将每点替换为 $m$ 个顶点，块间方向遵循 $T$。独立模型的各内部块独立均匀取自全部标号锦标赛；正则模型则独立均匀取自全部正则锦标赛，因此要求 $m$ 为奇数。Hamilton 圈按循环起点识别，记两种真实有限样本期望为 $c_{\rm ind}(T,m)$、$c_{\rm reg}(T,m)$，并设

\[
N=dm,\qquad \nu_N=\frac{(N-1)!}{2^N}.
\]

圆环基图 $\mathrm{Car}_d$ 在 $\mathbb Z/d\mathbb Z$ 上满足 $i\to j\iff1\le(j-i)\bmod d\le(d-1)/2$。普通同构只重新标号并保持边方向。

形式化以每个无序顶点对的一位布尔选择编码锦标赛，每个标号锦标赛恰好出现一次。正则样本是真正满足度数约束的有限子集，奇阶圆环保证它非空。圈由单轨道后继置换表示，所以无需在最终计数中再次除去起点。这些定义直接落实原问题中的“均匀”“正则”和“圈数”。

:::

::: {.theorem title="原编号猜想1、2、6"}

- **原猜想 1：** 对每个奇数 $d\ge3$，存在共同阈值 $M_d$，使所有 $m\ge M_d$ 和所有 $d$ 阶基图 $T$ 都满足 $c_{\rm ind}(T,m)\le c_{\rm ind}(\mathrm{Car}_d,m)$。已证明的加强结论还给出：取等当且仅当普通同构于圆环。
- **原猜想 2：** 对每个奇数 $d\ge3$，真实正则块模型的内层极限 $r_d=\lim_{m\to\infty,\ m\text{ 奇}}c_{\rm reg}(\mathrm{Car}_d,m)/\nu_{dm}$ 存在；随后沿奇数 $d\to\infty$ 的外层极限存在。其值为 $\cosh(1)/\cos(1)$。这里始终先固定 $d$ 再令 $m\to\infty$。
- **原猜想 6：** 对每个 $d\ge3$ 的正则基图，原对数角函数的 Hessian 行列式 $\mathcal H\ne0$，且 $d/\mathcal H$ 是有理数的平方。

:::

::: {.definition title="符号矩阵与谱常数"}

若 $A$ 为邻接矩阵，统一记

\[
S=2A+I-J,\quad C=S/d,\quad
\rho(T)=\frac{\det(I+C)}{\det(I+iC)}.
\]

正则时 $S^T=-S$、$S\mathbf1=0$，且下面证明 $\rho(T)\in\mathbb Q_{>0}$。

:::

## 猜想 6：把原 Hessian 压缩成有限矩阵

::: {.theorem title="原始解析Hessian"}

从原行列式 $K(y)=\det(I-(A+I/2)\operatorname{diag}y)$ 出发，其中对角矩阵在右。在 $z=2/d$ 附近解出末变量 $y_d=h(y_1,\ldots,y_{d-1})$，再对 $\log h(ze^{i\theta_1},\ldots,ze^{i\theta_{d-1}})$ 求实角变量二阶导数。结果本身为实矩阵，因此与取实部后的 Hessian 一致。证明先核对分母非零与局部解析性，求导后得到

\[
\mathbf H=E^TQE,\qquad
Q=(I+C^2)(I-C^2)^{-1},\quad
E=(e_1-e_d,\ldots,e_{d-1}-e_d).
\]

:::

::: {.proof title="压缩、行列式与有理平方"}

因为 $\|C\|_F^2=(d-1)/d<1$，所以 $Q\succ0$，压缩仍正定。又 $Q\mathbf1=\mathbf1$，而 $E$ 是 $\mathbf1^\perp$ 的一组非正交坐标，其 Gram 行列式为 $d$。因此

\[
\mathcal H=d\det Q
=d\frac{\det(I+C^2)}{\det(I-C^2)}>0,
\qquad \frac d{\mathcal H}=\rho(T)^2.
\]

最后用实有理反对称矩阵的行列式恒等式及正性，证明这个平方根恰为正有理数。这里没有把候选矩阵定义成原 Hessian；两者的对应本身就是已证明的结论。

:::

## 猜想 1：实际计数极限、谱比较与有限阈值

::: {.lemma title="真实独立块圈数的精确公式"}

令 $B=A+I/2$。给真实圈选择起点，再按块字分组，得到精确有限公式

\[
c_{\rm ind}(T,m)=\frac{(m!)^d}{dm}
 \sum_{\substack{f:\mathbb Z/(dm)\to[d]\\|f^{-1}(j)|=m\ \forall j}}
 \prod_t B_{f_t f_{t+1}}.
\]

:::

::: {.theorem title="独立内部块的实际期望极限"}

这保留了对向弧的依赖关系；两个重数分别来自起点和块内标号。正则基图对应 Markov 矩阵 $P=2B/d=J/d+C$。有限收缩证明唯一临界相位，局部二次展开、精确 Gaussian 积分与 Stirling 渐近遂给出实际极限

\[
\frac{c_{\rm ind}(T,m)}{\nu_{dm}}\longrightarrow\rho(T).
\]

:::

::: {.proof title="谱比较、取等及共同阈值"}

接下来比较真实符号矩阵的所有幂矩。一步弱主序、带权前缀和与迭代，给出相对于全序符号矩阵的 Frobenius 矩上界；奇阶圆环经符号切换具有相同矩。再代入收敛级数

\[
\log\rho(T)=\sum_{r\ge0}\frac{\|C^{2r+1}\|_F^2}{2r+1},
\]

便得圆环的谱常数最大。取等分析回推四次迹等号；四点恒等式产生切换全序，正则性再迫使切换符号交替，最终得到**普通同构**于圆环。

这里“弱主序”只比较从大到小排列后每个前缀的和。对任意非负递减权重，分部求和把前缀比较变为加权和比较；分别以两向量的坐标作权重，便得平方和比较，再展开差向量的平方和得到取等条件。这样把较长的凸函数论证缩成有限求和，也使严格取等如何传回图结构更容易检查。

非正则基图另用真实圈数的永久式上界处理，其归一化期望趋零。固定 $d$ 时基图仅有限多个：每个非圆环同构类都有严格极限差，取所有相应阈值的最大值，就是同时适用于全部基图的 $M_d$。

:::

## 猜想 2：统一包含概率与正则修正

::: {.lemma title="正则块的一致包含概率"}

对一条真实圈，设块内规定弧集为 $D$，弧数为 $a$，入出弧同时存在的顶点数为 $b$。证明对所有合法部分置换弧集一致有

\[
\Pr_{\rm reg}(D)=2^{-a}e^{b/m}(1+o(1)).
\]

:::

::: {.proof title="增长维积分中的统一估计"}

关键是实际 Fourier 积分的增长维分析。余弦对数的四次项在标准 Gaussian 尺度下趋于 $1/2$，故分子、空弧集分母都有公共因子 $e^{-1/2}$，比值中精确相消。删边 Laplacian 与有向端点相位合并后留下正号修正 $e^{b/m}$。非中央区域用圆弧聚类分解，始终保留随维数变化的精确 Gaussian 体积，再以统一 $L^2$ 界控制尾部；没有使用固定维近似代替增长维结论。

主峰半径选为 $r_m=m^{-3/8}$。全边数至多 $m^2$，规定边数至多 $m$，因此 Taylor 总误差至多 $m^2r_m^6+2mr_m^4\to0$。保留精确体积很关键：若每个坐标都损失固定倍数，累乘后可能成为无法忽略的指数误差。证明中的区域拆分同时给出所用函数的可积性。

:::

::: {.theorem title="正则内部块的实际期望极限"}

还需把这个修正平均回真实圈权重。Markov 开路径每步保持原标号的旗标恰为参数 $1/d$ 的独立 Bernoulli 变量；相邻两旗为真对应连续三次同标号。指数浓度经闭路边界和严格的平衡占用条件化后仍成立，得到 $b/m\to1/d$。有限根标号对应于是给出

\[
\frac{c_{\rm reg}(T,m)}{\nu_{dm}}\longrightarrow e^{1/d}\rho(T).
\]

:::

::: {.proof title="有界修正与后续外层极限"}

条件化的分母由已证明的独立模型计数极限与 Stirling 渐近控制，代价只呈多项式，不能抵消指数浓度。又因 $0\le b/m\le d$，指数修正一致有界，坏事件对平均的贡献也趋零。

圆环的行列式闭式为

\[
r_d=e^{1/d}
\frac{(1+1/d)^d+(1-1/d)^d}
{(1+i/d)^d+(1-i/d)^d}
\longrightarrow\frac{\cosh1}{\cos1}.
\]

内层模型极限与外层闭式极限分别证明，因此没有交换两重极限。上述每段均对应实际有限样本、原解析函数或其已证等价形式；不是对另一个抽象目标的条件验证。

:::

这些结论比较随机模型的期望，并不表示每个随机样本都达到极值，也不证明原猜想 3 关于所有充分大阶锦标赛的精确 Hamilton 圈极值。路径类比、严格单调性及高阶加强仍应与这里三个已验收的主命题分开阅读。
